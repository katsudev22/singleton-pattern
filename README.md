# singleton-pattern
my study of the **singleton pattern** for games, using **monogame** for rendering and the main loop.
https://gameprogrammingpatterns.com/singleton.html

## controls
<kbd>escape</kbd> -> pause the game |
<kbd>space</kbd> -> jump

## how to run
```bash
git clone https://github.com/katsudev22/singleton-pattern.git
cd singleton-pattern
dotnet run
```
